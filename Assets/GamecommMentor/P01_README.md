# Daeng Saka — Patch 1A.1B: Exploration Movement & Camera

Menu: **GamecommMentor → Daeng Saka → Create Exploration Test Scene**.

Gunakan WASD / tombol panah. Klik Game view agar menerima input.

Paket menyediakan gerak Saka, collider 3D, Animator idle/walk empat arah, serta kamera mengikuti dengan sudut tetap. Rincian instalasi, perubahan metadata sprite, dan tiga tes penerimaan ada di `INSTALL_1A_1B.md` pada root ZIP/proyek.

Persiapan sumber menyesuaikan delapan sheet idle/walking Saka. Backup `.meta` asli disimpan di `Library/GamecommMentor/P01`; lokasi lengkap ditampilkan di Console. PNG sumber tetap utuh. Path teknis P01 dan GUID dipertahankan untuk kompatibilitas dengan paket awal; nama resmi tahapnya adalah 1A.1B.

Kompilasi Unity/shader dan pengujian Play Mode belum dijalankan oleh pembuat paket. Jalankan Test 1–3 di Unity sebelum melanjutkan tahap interaksi/dialog.
